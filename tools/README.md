# tools

## gen-commands.py: the console command reference

`content/docs/commands/` (except `_index.de.md`) is generated from the console grammar of the
Onesimus Director. Do not edit those pages by hand; change the grammar in the Director and
regenerate. Python 3, standard library only.

1. Get the grammar, either
   - from a running Onesimus Director: in API mode 2 the command `.grammar` prints it as JSON
     (`{"grammar": {"schema": 1, "commands": [...]}}`), e.g. type `.api 2` and then `.grammar`
     in `oconsole` and save the JSON reply to a file, or
   - from the copy in the onesimus-dird repository: `docs/wiki/commands/console-grammar.json`.
2. Regenerate:

   ```sh
   tools/gen-commands.py path/to/console-grammar.json
   ```

   Without an argument the script reads `~/.cache/onesimus-agents/website/console-grammar.json`.
   `--out DIR` writes somewhere else than `content/docs/commands/`.
3. Check with `hugo --gc --minify -d /tmp/site-check` and commit the changed pages.

The output is deterministic: an unchanged grammar changes no file. Pages of commands that are
no longer in the grammar are deleted (only files carrying the "generated by" marker).
References to unknown commands (see also, value sources) are printed as warnings.
